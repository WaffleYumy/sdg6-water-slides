## Presenting

| Key | Action |
| --- | --- |
| Click, → or Space | Next slide or next build |
| ← | Back |
| N | Speaker notes |
| P | Presenter view (notes, timer, next slide) in a second window |
| F | Full screen |

- **Slide 3:** what SDG 6 is (targets 6.1, 6.2, 6.4), how far off the world is, and why it is our problem.
- **Slide 4 poll:** tap an option for each raised hand (Shift-tap removes one), then click to show the answer.
- **Slide 6:** ChatGPT vs. almonds. Take a show of hands, then click to tip the scale and click again for the 30-years punchline.
- **Slide 7:** live counters over two 3D Olympic pools at night. A column of water fills the almond pool every ~23 s and each full pool lifts out into a growing row; ChatGPT's pool gets a drip.
- **Slide 8:** not off the hook: same use, different water; the real AI problem is electricity (click for the electricity side).
- **Slide 9:** the leak counter runs live while the slide is open.
- **PDF:** print the page (Ctrl+P → Save as PDF). You get one slide per page with every build shown.

Everything is in `index.html`.
